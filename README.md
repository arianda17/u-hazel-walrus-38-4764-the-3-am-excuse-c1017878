# The 3 AM Excuse

`I guard your keys from the 3 AM version of you. That version can't read the screen, can't be trusted with keys, and isn't signing tonight.`

Run it with `node main.ts` — it prints the single entry line and nothing else.

At 3 AM the device regards its holder as an impaired impostor and blocks that impostor from reaching the keys.
Its secure element keeps office hours, and 3 AM is not one of them.
My entropy source produces nothing but yawns at 3 AM, and I refuse to sign a transaction built on tired random numbers.
